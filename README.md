# ⚖️ 民事法律助手系统

基于《民法典》的智能法律辅助系统，提供知识库管理、智能问答、法条检索和案例分析功能。

## 项目简介

本项目是一个基于检索增强生成（RAG）技术的法律助手系统，实现了从法律知识库构建到智能法律问答的完整流程。用户可以上传《民法典》原文和判决文书构建专业知识库，然后通过自然语言进行法律问题咨询、精确的法条检索以及类案分析。

## 技术栈

| 组件 | 技术 |
|------|------|
| 前端框架 | Streamlit (多页面应用) |
| RAG 框架 | LangChain |
| 向量数据库 | Chroma |
| 嵌入模型 | DashScope text-embedding-v4 |
| 大语言模型 | 通义千问 qwen3-max |
| 对话存储 | JSON 文件 |
| PDF 解析 | PyMuPDF (fitz) |
| Word 解析 | win32com (Microsoft Word) |

## 功能特性

### 📚 知识库管理
- **多格式文档支持**：TXT、PDF、DOC、DOCX
- **文档类型分类**：支持《民法典》原文、判决文书、通用文档
- **智能解析**：自动识别文档结构，提取关键信息
- **去重机制**：基于 MD5 哈希值避免重复内容入库

### 💬 智能问答
- **混合检索模式**：结合向量检索和关键词检索
- **多种检索策略**：精确检索、语义检索、章节检索
- **类案推送**：基于问题自动推荐相关案例
- **法条引用**：智能识别并展示引用的法律条文

### 📖 法条检索
- **精确搜索**：按法条编号快速定位（第1条-第1260条）
- **概念搜索**：按法律概念查找相关法条
- **范围检索**：批量查看指定范围的法条
- **章节浏览**：按编、章、节结构浏览法条

### ⚖️ 案例分析
- **案情分析**：自动识别案件类型和关键要素
- **类案推送**：基于案情描述推荐相似案例
- **法条推荐**：分析类案适用的法律条文
- **快速工具**：常用法条速查、示例案情

## 环境配置

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖包括：
- streamlit
- langchain
- langchain-community
- langchain-chroma
- dashscope
- chromadb
- pymupdf
- pywin32（用于DOC文件解析）

### 2. 配置环境变量

在项目根目录创建 `.env` 文件，配置以下环境变量：

```env
DASHSCOPE_API_KEY=your_api_key_here
```

## 使用方法

### 启动多页面应用（推荐）

```bash
streamlit run app_main.py
```

这将启动完整的多页面应用，包含以下模块：
- **首页**：系统概览和使用指南
- **📚 知识库更新**：上传和管理法律文档
- **💬 智能问答**：与法律助手对话
- **📖 法条检索**：搜索和浏览《民法典》法条
- **⚖️ 案例分析**：分析案情并获取相关案例

### 独立运行特定页面

如果您只想运行某个特定页面，也可以直接运行：

```bash
# 知识库管理
streamlit run pages/1_知识库更新.py

# 智能问答
streamlit run pages/2_智能问答.py

# 法条检索
streamlit run pages/3_法条检索.py

# 案例分析
streamlit run pages/4_案例分析.py
```

### 首次使用流程

1. **配置环境变量**：在 `.env` 文件中设置 `DASHSCOPE_API_KEY`

2. **上传知识库**：
   - 进入「📚 知识库更新」页面
   - 上传《民法典》PDF 文件（设置为"《民法典》原文"类型）
   - 上传判决文书示例（设置为"判决文书"类型）

3. **开始使用**：
   - 进入「💬 智能问答」页面进行法律咨询
   - 进入「📖 法条检索」页面浏览法条
   - 进入「⚖️ 案例分析」页面分析案情

## 配置说明

编辑 `config_data.py` 文件调整系统参数：

```python
# 向量数据库配置
collection_name = 'rag'                  # 数据库表名
persist_directory = './chroma_db'        # 数据库存储路径

# 文本分割配置
chunk_size = 1000                        # 分割块大小
chunk_overlap = 100                      # 相邻块重叠字符数
max_split_char_number = 1000             # 触发分割的阈值

# 模型配置
embedding_model_name = 'text-embedding-v4'  # 嵌入模型
chat_model_name = 'qwen3-max'               # 对话模型
```

## 注意事项

1. 首次使用需配置 `DASHSCOPE_API_KEY`
2. 支持的输入文件格式：TXT、PDF、DOC、DOCX
3. PDF 支持文本提取（不支持扫描件的 OCR 识别）
4. Word 文档需要 Windows 系统且安装 Microsoft Word
5. 建议单文件大小不超过 50MB
6. 对话历史自动保存到本地 JSON 文件
7. 首次使用建议先上传《民法典》PDF 构建基础法律知识库
